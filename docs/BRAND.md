# Nibria visual identity

Nibria is the proposed on-screen name for StudyOS. The repository, Supabase project, database schema and existing Site address are retained.

## Mark
An open book conveys the editable curriculum and practice records; the small spark represents steady progress. The same mark appears in the app, browser tab and installable app icons. Source vector: `public/mark.svg`. Raster icons: `public/icon-192.png` and `public/icon-512.png`.

## Palette
- Ink: `#1c2237` for primary text.
- Iris: `#6153d8` for actions and navigation.
- Deep iris: `#2d2a68` for the dashboard welcome area.
- Mint: `#49ad9e` for positive, secondary accents.
- Canvas: `#f5f7fb` behind white panels.
- Border: `#e6e9f3` between surfaces.

## Motion
Page sections enter once with short easing. Interactive surfaces lift only on hover-capable devices. The dashboard mark drifts subtly. Reduced-motion preferences disable these effects.

## Product language
Tawjihi, SAT, IELTS, applications, tasks and analytics keep their established meanings. SAT remains a user-entered companion answer sheet: no College Board questions are included or generated.

The name is a working creative choice; check trademark and domain availability before any external brand registration.
